# Summaya Shaikh — Portfolio

Personal portfolio website for Summaya Shaikh, a final-year BSCS student and aspiring AI/ML Engineer.

🔗 **Live site:** [summaya-portfollo.netlify.app](https://summaya-portfollo.netlify.app)

## About

Single-page portfolio showcasing:
- AI/ML projects (PakJobAI, AI Resume Analyzer, Disaster Warning System, and more)
- Work experience and internships (FlyRank, Vortex Tech, CodeAlpha)
- Final Year Project — Intelligent Real-Time Classroom Monitoring System (YOLOv8, ArcFace, MediaPipe)
- Skills, certifications, and contact form

## Tech Stack

- HTML, CSS, and vanilla JavaScript (no framework)
- Google Fonts (Space Grotesk, Inter, JetBrains Mono)
- Netlify Forms for the contact form
- Deployed on Netlify

## Structure

```
index.html   → main page (all content, styles, and scripts in one file)
favicon.svg / favicon-32.png / favicon-180.png → site icons
og-image-final.png → social share preview image
```

## Deployment

This site auto-deploys to Netlify on every push to the `main` branch.
